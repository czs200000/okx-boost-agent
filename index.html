OKX Boost Agent

An AI market-making agent for X Layer: DeepSeek-driven decisions, 0-gas execution, and an on-chain audit ledger so every trade is verifiable.

What it does

  • Runs limit-order market making on X Layer (e.g. NVDAx/USDT) with strict buy/sell alternation and inventory-neutral rotation.
  • Uses a large language model (DeepSeek) as an advisor, with deterministic local risk controls as the final authority.
  • Trades with 0 gas / 0 service fees via OKX DEX on X Layer.
  • Records every decision on-chain in an auditable ledger (this contract), including action, token, price and timestamp.
