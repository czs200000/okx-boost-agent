# Contributing

Contributions are welcome through focused pull requests.

1. Do not include credentials, wallet sessions, personal information, or live transaction state.
2. Keep real execution disabled by default.
3. Add or update tests for strategy, risk, execution, and parsing changes.
4. Run `npm run check` before opening a pull request.
5. Explain user impact and any financial or operational risk in the pull-request description.

Changes that bypass wallet confirmations, OKX route warnings, deterministic risk controls, or campaign eligibility rules will not be accepted.
